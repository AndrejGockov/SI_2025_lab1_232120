Прво правиме pull requests и оставаме еден branch за да можеме локално да го споиме.
Откако ќе ги направиме pull requests, повикуваме: git pull origin master. За да добиеме сегашната состојба на master branch. Следно мењаваме во master branch и правиме merge so третиот branch

git pull origin master
git checkout master
git merge origin 4-sort-tasks-by-priority
git push -u origin master
